HE THONG QUAN LY THU VIEN - SPRING BOOT

1. Công nghệ
- Spring Boot
- Thymeleaf
- Spring Data JPA
- H2 Database
- Java 21
- Maven

2. Chạy project
- Mở project bằng Eclipse/IntelliJ
- Chạy file:
  src/main/java/com/thuvien/ThuVienApplication.java
- Mở trình duyệt:
  http://localhost:8080/login

3. Tài khoản mẫu
Username: admin
Password: 123456

4. Database
Project dùng H2 Database dạng file.
Dữ liệu được lưu trong thư mục:
data/thuvien

Có thể mở H2 Console:
http://localhost:8080/h2-console

JDBC URL:
jdbc:h2:file:./data/thuvien

User: sa
Password: để trống

5. Phần đã có
- Trang đăng nhập
- Kiểm tra tài khoản trong database
- Trang đăng ký
- Bảng users
- Thanh navbar
- Trang sau khi đăng nhập
- Giao diện responsive
